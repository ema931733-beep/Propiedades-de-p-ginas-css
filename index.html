10 Propiedades de CSS

WIDTH HEIGHT BORDER COLOR PADDING
COLOR

1. color

Cambia el color del texto.

color: #2e6f40;
BACKGROUND-COLOR

2. background-color

Cambia el color de fondo de un elemento.

background-color: #e6ede5;
FONT-SIZE

3. font-size

Cambia el tamaño de la letra.

font-size: 18px;
FONT-FAMILY

4. font-family

Cambia la tipografía o fuente del texto.

font-family: 'Segoe UI', sans-serif;
TEXT-ALIGN

5. text-align

Alinea horizontalmente el texto (izquierda, centro, derecha).

text-align: center;
MARGIN

6. margin

Establece el espacio exterior alrededor de un elemento.

margin: 20px auto;
PADDING

7. padding

Establece el espacio interior entre el contenido y su borde.

padding: 15px 25px;
BORDER

8. border

Agrega y define un borde alrededor del elemento.

border: 2px solid #a4c4ad;
WIDTH

9. width

Define el ancho de un elemento.

width: 100%;
HEIGHT

10. height

Define la altura de un elemento.

height: 50px;
